# 鼠鼠 Cleaner 可选清理与 Swag Cat 图标设计

日期：2026-08-21
状态：用户已逐节确认

## 1. 背景与问题

当前 GUI 能扫描到联想后台项目，但本机生成的 `pending_actions.json` 中没有可执行项，只有三个观察项：`HRWSCCtrl` 服务，以及两个联想通知/诊断计划任务。直接原因是规则使用 `contains`，执行安全闸门只允许本次实际命中为 `exact` 或 `path` 的目标执行；此外 `HRWSCCtrl` 当前被标记为 `safe=false` 且动作是 `none`。

现有桌面快捷方式使用的 `assets/shushu.ico` 只有 32×32、766 字节，高 DPI 和大图标显示质量不足，视觉也不符合用户指定的“三角洲鼠鼠”表情包方向。

## 2. 目标

1. 精确识别的 OEM 后台项目原则上都能由用户选择处理。
2. 每一项必须列出必要性、清理原因、功能影响、默认选择策略和恢复能力。
3. 安全自动项与有功能影响的用户主动项走不同授权路径，不能通过放宽现有安全闸门实现。
4. 已处理项目应明确展示当前状态，不制造仍可重复清理的假象。
5. 桌面快捷方式与 WPF 应用统一使用原创 Swag Cat 风格鼠鼠图标，并通过 Windows 多尺寸显示验收。
6. 高 CPU 可疑进程使用独立的一次性结束流程；只结束用户选中的当前进程实例，不删除文件或改变自启，且明确不可恢复。

## 3. 非目标与安全边界

- `contains`、`regex` 等宽匹配只能用于发现，不能直接授权执行。
- 不允许把 `safe=false` 简单改成 `true` 来绕过安全规则。
- 不直接复制现有 Swag Cat 表情包照片；最终资产只借鉴对称近景、写实橘猫、呆萌抽象和轻微低清的构图语言。
- 不把已禁用项目伪装成仍需清理。
- 不以管理员进程退出码为唯一成功依据；必须验证目标最终状态。

## 4. 规则与数据模型

### 4.1 执行类别

扫描结果分为三类：

- `automatic_safe`：经过实测且由 `exact/path` 实际命中的安全项，可默认勾选。
- `manual_impact`：由 `exact/path` 实际命中、允许用户主动处理但有功能影响的项目，默认不勾选并要求二次确认。
- `observation`：仅有宽匹配证据或身份不完整，不可执行。

### 4.2 规则展示字段

规则需要提供或归一化出以下字段：

```json
{
  "necessity": "optional",
  "default_selected": false,
  "requires_confirmation": true,
  "impact_cn": "可能影响联想电脑管家的安全状态、主动防护和通知",
  "cleanup_reason_cn": "不使用联想电脑管家时可减少常驻后台"
}
```

`HRWSCCtrl` 保持非自动安全属性，但增加精确服务名和用户主动动作 `disable_service`。两个联想任务增加精确任务名称或完整路径，动作保持 `disable_task`。宽匹配规则可以保留作发现后备，但不能提升执行资格。

### 4.3 Pending 记录

待处理记录必须绑定：

- 规则 ID、目标类型和动作；
- 实际命中的 pattern、type 和 field；
- 服务名、任务完整路径等精确目标身份；
- 扫描时当前状态；
- 执行类别、必要性、默认选择、确认要求；
- 中文清理原因与功能影响；
- 恢复所需的原状态信息引用。

管理员执行时必须用同一 matcher 和目标身份重新验证。扫描后目标改名、替换或身份变化时拒绝执行并要求重新扫描。

## 5. 当前目标项目策略

| 项目 | 必要性 | 执行类别 | 默认选择 | 动作 | 原因与影响 |
|---|---|---|---:|---|---|
| Lenovo OOBE 自动通知任务 | 不必要 | `automatic_safe` | 是 | `disable_task` | 主要负责联想通知，不影响 Windows 核心功能 |
| Lenovo UDC Diagnostic Scan | 通常不必要 | `automatic_safe` | 是 | `disable_task` | 后台诊断和数据采集，禁用后不再自动运行 |
| `HRWSCCtrl` / Lenovo Windows Security Center | 可选保留 | `manual_impact` | 否 | `disable_service` | 不使用联想电脑管家时可减少常驻后台；可能影响其安全状态、主动防护和通知 |

若目标已经禁用，状态显示为“已处理/已禁用”，不进入待执行子集。如果以后被 OEM 软件重新启用，再次扫描后恢复为可勾选状态。

## 6. GUI 信息架构与交互

扫描结果分组：

1. **建议清理**：安全、精确、可执行，默认勾选。
2. **可选清理**：精确、可执行但有功能影响，默认不勾选并突出影响。
3. **已处理/仅观察**：已禁用项目显示绿色完成状态；宽匹配未知项显示“需要精确识别”。

每张项目卡片显示：

- 名称和当前状态；
- 必要性标签；
- 清理原因；
- 可能影响；
- 动作和恢复能力；
- 折叠的匹配技术详情。

顶部统计采用：`建议清理 X 项 · 可选清理 Y 项 · 已处理 Z 项 · 仅观察 N 项`。

选择 `manual_impact` 项后，执行前显示独立二次确认框，逐项列出目标、影响和恢复说明。未经确认时不得把该项写入管理员执行子集。

## 7. 执行数据流

```text
只读扫描
→ 分类与状态展示
→ 用户勾选
→ 高影响项二次确认
→ 生成绑定审核身份的最小子集
→ 请求管理员权限
→ 同一精确 matcher 与当前身份重新验证
→ 备份原状态
→ 逐项执行
→ 查询并验证最终状态
→ 合并逐项结果并展示恢复入口
```

执行多项时逐项隔离。单项失败不应把其他项目误标失败，也不能把失败项误标成功。

## 8. 失败处理与恢复

- 用户取消 UAC：显示“用户取消授权，未执行任何操作”。
- 精确身份复核失败：拒绝该项并要求重新扫描。
- 备份失败：不执行该项。
- 系统命令失败：显示可操作错误信息并保留原状态。
- 命令返回成功但状态未改变：判定失败。
- 程序异常关闭：保留备份和诊断记录供下次查看。
- 恢复时只接受本软件创建并验证通过的备份。

服务备份至少保存原启动类型、原运行状态、服务名、二进制路径摘要、操作时间、规则 ID 和精确匹配证据。恢复后按原状态处理：原来运行则恢复启动类型并启动；原来停止则只恢复启动类型。

计划任务备份保存任务完整路径、原启用状态和可验证的任务定义。恢复后验证任务状态与备份一致。

## 9. 图标与快捷方式

视觉方向采用用户选择的 B：

- 原创写实橘猫超近景；
- 猫脸沿中心对称，形成 Swag Cat / 三角洲鼠鼠式呆萌抽象感；
- 右下角加入小型高对比清扫徽章；
- 背景透明，无文字；
- 浅色和深色桌面均保持清晰轮廓。

ICO 必须内置 `16、20、24、32、40、48、64、128、256 px`。同一图标应用到桌面 `鼠鼠 Cleaner.lnk`、WPF 窗口、任务栏和项目 GUI 启动入口。快捷方式说明为“安全识别并清理 OEM 后台组件”，启动时不显示 PowerShell 控制台窗口。

视觉验收包括 Windows 桌面小图标、中图标和高 DPI 实际截图，不能只检查文件存在。

## 10. 测试与验收

### 10.1 自动化测试

- 两个联想任务启用时由精确规则命中，进入 `automatic_safe` 且可勾选。
- 两个任务禁用后进入“已处理”，不产生重复动作。
- `HRWSCCtrl` 进入 `manual_impact`，可手动勾选但不默认勾选。
- 未完成二次确认时，`manual_impact` 不得进入执行子集。
- 混合 `exact + contains` 规则只能由本次实际命中的 `exact` 证据授权。
- 宽匹配或被篡改的 pending 记录不得执行。
- 扫描后目标身份或状态变化时执行失败关闭。
- 服务与任务的备份、执行、验证、恢复形成闭环。
- 快捷方式目标、参数、工作目录和 ICO 路径正确。

### 10.2 回归与真实验收

- Windows PowerShell 5.1 全量 Pester；
- PowerShell 7 全量 Pester；
- GUI 测试、旧版逻辑、Schema 和 PSScriptAnalyzer；
- `git diff --check`；
- 真实 GUI 扫描、勾选、UAC、执行、结果页和恢复；
- 实际桌面图标多尺寸与高 DPI 检查。

真实 UAC、真实系统状态变化和恢复闭环未观察完成前，不得把功能称为最终验收通过，也不得把本地实现描述为已推送或已发布。
